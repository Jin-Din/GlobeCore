GlobeCore Android API 开发帮助文档

面向 Android/Kotlin/Java 宿主开发人员：地图视图、XYZ 瓦片、本地栅格、三维地形、矢量、动态叠加层、拾取、坐标转换与 GDAL/OGR 文件能力。

Maven：com.zys:globecore:0.1.4.0minSdk 24ABI：arm64-v8a / x86_64OpenGL ES 2.0

1. SDK 概览

GlobeCore 是一套以 C++ 为核心的地图渲染引擎，Android 侧通过 Kotlin 门面类和 JNI 暴露能力。业务 App 通常只需要接触 com.zys.globecore 包下的公开类，不需要直接调用 NativeLib。

NativeMapView
继承 GLSurfaceView，负责地图显示、相机、瓦片/地形/矢量图层、手势、拾取和屏幕反算。
Camera / Position
描述相机姿态与地理坐标，经纬度单位为度，高度单位为米，角度单位为度。
VectorStyle / Extent
描述矢量样式和空间过滤范围，颜色统一使用 Android #AARRGGBB 整数。
TerrainProvider
支持 quantized-mesh 服务、磁盘缓存、自动跟随视口、并发请求、重试和事件状态。
NativeSrs
初始化 PROJ 数据并执行任意 CRS 坐标转换。
NativeVector / LayerInfo
读取/查询/写回矢量属性，获取图层四至、SRS、字段名、GDAL 信息。
适用范围：本文档覆盖 Android AAR 的公开 Kotlin API。Java 可通过 getter/setter、静态对象方法和回调互操作调用；示例以 Kotlin 为主。

2. 安装集成

2.1 Maven 仓库（推荐）

在 settings.gradle.kts 的 dependencyResolutionManagement.repositories 中加入 GitHub Pages Maven 仓：

dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven { url = uri("https://z-gis.github.io/GlobeCore/maven") }
    }
}

在 app/build.gradle.kts 中声明依赖：

android {
    defaultConfig {
        minSdk = 24
        ndk { abiFilters += listOf("arm64-v8a", "x86_64") }
    }
}
dependencies {
    implementation("com.zys:globecore:0.1.4.0")
}

2.2 手动引入 AAR

将 globecore-0.1.4.0-release.aar 放入 app/libs/，files 方式不会自动解析传递依赖，需要显式加入 AndroidX：

dependencies {
    implementation(files("libs/globecore-0.1.4.0-release.aar"))
    implementation("androidx.core:core-ktx:1.10.1")
}

2.3 权限与初始化

在线瓦片和地形需要网络权限；读取本地文件还需要宿主按 Android 版本处理存储权限或 SAF 授权。

<uses-permission android:name="android.permission.INTERNET" />

应用启动后、首次坐标转换前初始化 PROJ 数据：

class App : Application() {
    override fun onCreate() {
        super.onCreate()
        NativeSrs.initProjData(this)
    }
}
注意：initProjData 会把 AAR assets 中的 proj 数据解压到 context.filesDir/proj。已存在文件默认跳过；升级内置 PROJ 数据后如遇异常，可清除应用数据或删除该目录。

3. 快速开始

以下示例创建一个 3D 地图，加载影像底图、透明注记层和三维地形，然后飞到中国上方。

class MapActivity : Activity() {
    private lateinit var map: NativeMapView

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        NativeSrs.initProjData(this)
        map = NativeMapView(this)
        setContentView(map)

        val cache = filesDir.resolve("map-cache").absolutePath
        // @Jin 示例代码：实际项目请替换为自己的图源地址、token 与缓存目录。
        map.addTileLayer(
            cacheDir = "$cache/img",
            urlTemplate = "https://server.example.com/tiles/{z}/{x}/{y}.jpg",
            maxLevel = 18,
            overlay = false
        )
        map.addTileLayer(
            cacheDir = "$cache/cia",
            urlTemplate = "https://server.example.com/cia/{z}/{x}/{y}.png",
            maxLevel = 18,
            overlay = true
        )
        map.setViewMode(NativeMapView.ViewMode.THREE_D)
        map.setCamera(Camera(35.0, 105.0, 12_000_000.0, 0.0, 0.0))
    }

    override fun onResume() { super.onResume(); map.onResume() }
    override fun onPause() { super.onPause(); map.onPause() }
    override fun onDestroy() { map.destroy(); super.onDestroy() }
}
XYZ 顺序：不同服务商的 URL 行列顺序不同。OSM/很多 XYZ 服务是 {z}/{x}/{y}；ArcGIS World Imagery 常见为 {z}/{y}/{x}。接入前务必核对服务文档。

4. 生命周期与线程模型

  • NativeMapView 继承 GLSurfaceView，内部创建 OpenGL ES 2.0 上下文和渲染线程。
  • 默认渲染模式为 RENDERMODE_WHEN_DIRTY：静止时省电；手势、相机变化、瓦片异步到位会触发重绘。
  • 瓦片下载、磁盘缓存、解码等在 native 后台线程执行；纹理上传切回 GL 线程。
  • 矢量文件读取和三角剖分为异步流程，可通过 hasVectorLoading() 查询状态。
  • 公开 Kotlin 方法通常可在主线程调用；内部会完成必要的 JNI/native 转发。业务不要在 native 对象销毁后继续调用。
override fun onResume() { map.onResume() }
override fun onPause() { map.onPause() }
override fun onDestroy() { map.destroy() }

5. Camera 相机对象

data class Camera(
    val latitude: Double = 0.0,
    val longitude: Double = 0.0,
    val altitude: Double = 0.0,
    val heading: Double = 0.0,
    val tilt: Double = 0.0,
    val roll: Double = 0.0,
    val fieldOfView: Double = 45.0,
    val altitudeMode: Camera.AltitudeMode = Camera.AltitudeMode.ABSOLUTE,
)
字段类型说明
latitude / longitudeDouble相机位置经纬度，WGS84 十进制度。
altitudeDouble相机高度，单位米。2D 下该值参与 zoom 换算。
headingDouble航向角，单位度；主要在 3D 下消费。
tiltDouble俯仰角，单位度；native 通常钳制在可支持范围内。
rollDouble翻滚角，建模保留字段。
fieldOfViewDouble垂直视场角，默认 45 度。
altitudeModeEnumABSOLUTE、ABOVE_SEA_LEVEL、CLAMP_TO_GROUND、RELATIVE_TO_GROUND。枚举 ordinal 与 native 对齐，不要调整顺序。

7. VectorStyle 矢量样式

VectorStyle(
    fillColor = 0x664A8FE3.toInt(),

字段说明

10.4 XYZ 瓦片图层

addTileLayer

fun addTileLayer(
    cacheDir: String,
    urlTemplate: String,
    maxLevel: Int,
    overlay: Boolean = false
): Unit
cacheDir图层独立缓存目录。若路径以 .mbtiles 结尾，native 使用 MBTiles 单文件缓存；否则使用目录缓存。
urlTemplateURL 模板，支持 {z}、{x}、{y}。传空字符串表示禁用联网，只读本地缓存。
maxLevel服务支持的最大瓦片级别；超过后拉伸末级，避免无效 404。
overlaytrue 表示透明叠加层（如注记），缺失瓦片保持透明；false 表示底图。
索引说明：当前 Kotlin addTileLayer 方法返回 Unit，但 native 图层索引按添加顺序从 0 开始。业务应自行记录添加顺序；与 addRasterLayer 混用时，其 native layers 索引空间共享。

setLayerVisible

fun setLayerVisible(index: Int, visible: Boolean): Unit

设置图层可见性。隐藏后不绘制、不取瓦片。索引越界时 native 忽略。

removeTileLayer

fun removeTileLayer(index: Int): Unit

移除在线瓦片或 addRasterLayer 添加的图层。native 使用墓碑方式保留其他层 index 稳定，后台队列会清理，GL 纹理下一帧释放。

10.5 本地栅格

addRasterLayer

fun addRasterLayer(cacheDir: String, path: String): Int

加载 GDAL 可打开的本地栅格（tif/img 等），native 重投影并按全球墨卡托即时切片，缓存可复用。成功返回图层索引，失败返回 -1。

rasterAddError

fun rasterAddError(): String?

返回最近一次本地栅格添加失败原因。

addRasterImageLayer

fun addRasterImageLayer(cacheDir: String, path: String): Int

整幅直读单张贴图并按 WGS84 四至贴面。UI 线程立即返回，超大图按 overviews 降采样；非空缓存目录启用 sidecar 磁盘缓存。

setRasterImageVisible / hasRasterLoading / rasterImageError

fun setRasterImageVisible(index: Int, visible: Boolean): Unit
fun hasRasterLoading(): Boolean
fun rasterImageError(index: Int): String?

控制整幅栅格可见性、查询是否仍在加载、读取错误信息。

10.6 三维地形 Provider

configureTerrainProvider

fun configureTerrainProvider(
    baseUrl: String,
    cacheDir: String,
    maxZoom: Int = 15,
    concurrency: Int = 4,
    tileRadius: Int = 3,
    headers: Map<String, String> = emptyMap()
): Boolean

配置 quantized-mesh v1.0 地形服务。baseUrl 应为服务根地址，native 会拉取 layer.json，解析模板并请求 terrain 瓦片。返回 false 表示句柄无效或配置失败。

maxZoom本地允许使用的最大地形级别，防止请求过量或超过服务能力。
concurrency地形下载并发数，弱网建议 2-4。
tileRadius围绕当前视口预取半径，越大覆盖越好但请求更多。
headersHTTP 请求头，如 token、Referer 等。

setTerrainProviderEnabled

fun setTerrainProviderEnabled(enabled: Boolean): Boolean

开启/关闭地形。关闭时 native 清空 DEM 注入缓存，重新开启后按当前视口恢复。

refreshTerrainProvider / setTerrainProviderAutoFollow / prefetchTerrainProviderMetadata

fun refreshTerrainProvider(): Unit
fun setTerrainProviderAutoFollow(enabled: Boolean): Unit
fun prefetchTerrainProviderMetadata(): Unit

refresh 手动刷新当前视口地形；autoFollow 控制相机变化后是否自动跟随加载；prefetch 可提前加载元数据。

terrainProviderStatus / setOnTerrainProviderEventListener

fun terrainProviderStatus(): String
fun setOnTerrainProviderEventListener(listener: ((String) -> Unit)?): Unit

状态和事件回调均为 JSON 字符串。Kotlin 监听器由 onTerrainProviderEvent 投递到视图主线程；业务一般不直接调用 onTerrainProviderEvent。

10.8 文件矢量图层

addVectorLayer

fun addVectorLayer(
    path: String,
    style: VectorStyle,
    iconArgb: IntArray? = null,
    iconW: Int = 0,
    iconH: Int = 0,
    extent: VectorExtent? = null,
    maxFeatures: Int = 0
): Int

加载 GDAL/OGR 可打开的 shp、kml、kmz、geojson、gpkg 等文件。成功返回图层索引，失败返回 -1。extent=null 表示全量加载；maxFeatures=0 使用 native 保护上限。

@Jin 实验性在线 GeoJSON URL

当前 path 参数除本地文件外，也可直接传入公开 http:// 或 https:// GeoJSON 地址。该能力为 P0 实验特性：native 先下载到应用私有缓存，再交给 GDAL/OGR 解析，不依赖 GDAL /vsicurl/。

val provinceUrl = "http://210.74.129.84:8520/app-pub/web-data/geojson/district/province.json"
val index = map.addVectorLayer(
    path = provinceUrl,
    style = VectorStyle(labelField = "name"),
    extent = null,
    maxFeatures = 0
)
缓存目录context.filesDir/globecore/vector-cache/url/<hash>.geojson
重复请求同一 URL 首次成功后只读缓存；updateVectorExtent() 不会重复下载。
响应限制P0 默认超时 20 秒、最大 80MB；空响应、HTML 错误页、缺少 type 的非 GeoJSON 会失败。
鉴权能力P0 仅支持公开 URL；headers、token、ETag、强制刷新、进度回调列入后续版本。
回退将 native 常量 RemoteVectorCache::kExperimentalRemoteGeoJsonSource 改为 false。

updateVectorExtent

fun updateVectorExtent(index: Int, extent: VectorExtent?, maxFeatures: Int = 0): Unit

相机移动后按新的 WGS84 范围重新加载矢量。传 null 恢复整文件。

状态、字体、可见性与移除

fun hasVectorLoading(): Boolean
fun setFontPath(path: String): Unit
fun setVectorLayerVisible(index: Int, visible: Boolean): Unit
fun setVectorMinLevel(index: Int, minLevel: Int): Unit

查询加载状态、设置标注字体文件、控制显隐、设置最小显示级别和删除图层。

10.9 动态叠加层

动态 overlay 适合业务轨迹、测量、临时点、点击高亮等数据。更新接口为覆盖式更新：每次传入该图层当前应显示的完整数据。

fun clearOverlayLayers(): Unit

创建动态图层并返回索引。3D 地形开启后，线面几何会进行 DEM 贴地烘焙。

fun updateOverlayPoints(

    lonlat: DoubleArray,
    fids: LongArray? = null,

updateOverlayLines

fun updateOverlayLines(

    vertexCounts: IntArray,
    fids: LongArray? = null,
    labels: Array<String>? = null

更新一条或多条线。vertexCounts 描述每条线的顶点数，所有顶点数之和必须等于坐标对数。

updateOverlayPolygons

设置业务叠加层是否参与拾取。测量线、临时辅助面等不希望挡住底图层拾取时可设为 true。

10.10 拾取、反算与要素几何

fun pickVector(sxPx: Float, syPx: Float): LongArray?

fun featureGeometry(layerIndex: Int, fid: Long): FeatureGeometry?

pickVector 命中时返回 longArrayOf(layerIndex, fid)，未命中返回 null。拾取优先动态 overlay，再文件矢量；同阶段后加入图层优先，并尊重 noPick。featureRenderColor 返回 [fillArgb, lineArgb]。

11. NativeSrs 坐标转换

object NativeSrs {
    fun initProjData(context: Context): Unit
    external fun initProjDataPath(projDataPath: String?): Unit
    external fun convert(x: Double, y: Double, srcCrs: String, tgtCrs: String): DoubleArray?
    external fun getProjVersion(): Int
}
initProjData解压 AAR 内置 PROJ 数据到 filesDir/proj 并设置搜索路径。
convert执行坐标转换，成功返回 [x,y]，失败返回 null。CRS 可传 EPSG 或 PROJ 字符串。
getProjVersion返回 PROJ 主版本号。
val xy = NativeSrs.convert(116.4, 39.9, "EPSG:4326", "EPSG:3857")
if (xy == null) { /* 转换失败兜底 */ } else { val mercatorX = xy[0] }

12. NativeVector 矢量文件 IO

object NativeVector {
    external fun readVectorFeatures(
        path: String,
        minLon: Double, minLat: Double, maxLon: Double, maxLat: Double,
        includeAllFields: Boolean,
        labelField: String?,
        simplifyGeometry: Boolean,
        simplifyTolerance: Double
    ): String?
    external fun getFeatureAttributes(path: String, featureId: Long): String?
    external fun queryVectorFeatures(path: String, sql: String): String?
    external fun countVectorFeatures(path: String): Int
    external fun updateFeatureAttributes(
        path: String, featureId: Long, keys: Array<String>, values: Array<String>
    ): Boolean
}
  • 范围任一传 NaN 表示不做空间过滤。
  • includeAllFields=false 时仅保留 labelField 字段，减少大数据量内存。
  • 返回 JSON 字符串；SQL 错误通常以 JSON 中的 error 字段表达。
  • countVectorFeatures 打开失败返回 -1。
  • 属性写回依赖驱动和文件权限，只读驱动返回 false。

    // 可用 org.json.JSONObject 解析
}
map.configureTerrainProvider(baseUrl, cacheDir.absolutePath)
map.setTerrainProviderEnabled(true)
事件触发时机
metadata_started开始加载 layer.json。
metadata_ready元数据就绪，额外字段 source=disk/network。
refresh_started开始刷新当前视口，含 engineZoom、engineTiles、queued。
first_tile本轮首块地形注入完成，可用于首块耗时统计。
progress加载进度，含 delivered、total、failures。
refresh_completed本轮完成，含 delivered、total、failures。
enabled / disabled地形开关变化。
error错误，stage 表示阶段，如 metadata、metadata_parse。

stats 常用字段

enabled / metadataLoaded / maxZoom开关、元数据状态、最大级别。
engineZoom / requestedEngineTiles / requestedServiceTiles引擎地形级别、请求的引擎块数、换算后的服务瓦片数。
deliveredTiles / failures / retries已注入块数、失败数、重试数。
diskHits / networkRequests / cacheWrites地形磁盘命中、网络请求、缓存写入次数。
metadataDiskHits / metadataNetworkRequestslayer.json 缓存和网络请求次数。
availableSkips / duplicateSkips已有数据跳过、重复任务跳过次数。
firstTileMs / elapsedMs首块耗时和本轮总耗时。

15.3 点选文件矢量并高亮

map.setOnTapListener { x, y ->
    val hit = map.pickVector(x, y) ?: return@setOnTapListener
    val layer = hit[0].toInt()
    val fid = hit[1]
    val geom = map.featureGeometry(layer, fid) ?: return@setOnTapListener
    val highlight = map.addOverlayLayer(VectorStyle(fillColor = 0x55FFCC00.toInt(), lineColor = 0xFFFF8800.toInt()))
    when (geom.type) {
        0 -> map.updateOverlayPoints(highlight, geom.lonlat)
        1 -> map.updateOverlayLines(highlight, geom.lonlat, geom.ringCounts)
        2 -> map.updateOverlayPolygons(highlight, geom.lonlat, geom.ringCounts, geom.ringsPerFeature)
    }
}

fun Bitmap.toArgb(): Triple<IntArray, Int, Int> {
    val pixels = IntArray(width * height)
    getPixels(pixels, 0, width, 0, 0, width, height)
    return Triple(pixels, width, height)
}

16. 排错指南

现象可能原因处理建议
UnsatisfiedLinkError: libglobecore.so宿主 ABI 不匹配或 APK 未包含 .so。确认 abiFilters 包含 arm64-v8a；模拟器使用 x86_64。
坐标转换返回 nullPROJ 数据未初始化或 CRS 字符串非法。Application/onCreate 调 NativeSrs.initProjData；检查 EPSG 编号。
在线瓦片不出图无网络权限、URL 模板错误、token 过期、x/y 顺序反了。检查 INTERNET、{z}/{x}/{y} 顺序、服务响应格式和缓存目录。
注记层黑底或不透明把 PNG 注记当作底图 overlay=false。注记层 addTileLayer 时 overlay=true。
在线 GeoJSON 提示下载失败网络不可达、HTTP 非 2xx、超时或服务证书/连接异常。检查 INTERNET 权限、URL、服务状态和 logcat 中脱敏后的 [RemoteGeoJson] 日志。
http 明文地址在真机失败Android 9+ 默认限制 cleartext HTTP。仅在内网调试时配置 networkSecurityConfig 或 usesCleartextTraffic；生产优先使用 HTTPS。
在线 GeoJSON 提示不是 GeoJSON服务返回登录页/HTML、空内容或非 GeoJSON JSON。用浏览器直接访问 URL；P0 只做轻量嗅探，最终仍由 OGR 解析。
在线 GeoJSON 超过大小限制响应超过 P0 默认 80MB。服务端切片/分省裁剪，或后续在 options 中开放 maxNetworkBytes。
地形没有起伏仍在 2D、地形未开启、layer.json 失败、服务不兼容。切 THREE_D，检查 terrainProviderStatus 与 error 事件。
大 GeoJSON 卡顿一次加载顶点过多、三角剖分和上传压力大。使用 extent/maxFeatures、简化几何、分视口加载、减少复杂洞环。
拾取不到 overlay图层被设置 noPick 或被后加入图层优先命中。检查 setOverlayNoPick 和图层添加顺序。
升级 AAR 后 PROJ 异常filesDir/proj 中旧数据残留。清除应用数据或删除 proj 解压目录后重启。
