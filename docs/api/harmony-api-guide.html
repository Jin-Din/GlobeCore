面向 HarmonyOS NEXT（纯血鸿蒙）宿主开发人员与 AI 编程助手：本文覆盖分发包内全部公开 ArkTS API， 每个 API 含签名、参数说明与可直接改写的使用示例。引擎核心为 C++ 共享库 libglobecore.so， ArkTS 门面只做转发，相机、瓦片、缓存、矢量三角剖分、GLES2 绘制全部在 native 完成。

1. SDK 概览与能力速查

GlobeCore 是独立实现的 C++ 地图渲染引擎，HarmonyOS 侧经 NAPI 暴露为 HAR 形态。宿主通常只接触 NativeMapView 组件与少量静态门面类，不需要直接调用 NAPI。

2. 安装集成

2.1 分发包内容

@Jin 命名约定：分发包文件名必须带构建形态标记——lite 构建（GLOBECORE_LITE=ON）命名为 globecore-harmony-next-<version>-lite（zip 同名）；全量构建命名不带 lite。本文档随 lite 包发布。
globecore-harmony-next-0.1.5.0-dev/
├── libs/arm64-v8a/libglobecore.so     # 引擎本体（release，NAPI 模块名 globecore）
├── libs/arm64-v8a/libc++_shared.so    # C++ 运行时
├── ets/                               # ArkTS 门面源码（Index.ets 为统一导出）
├── types/libglobecore/index.d.ts      # NAPI 全量类型声明
├── resources/rawfile/ca/cacert.pem    # HTTPS CA 包
├── module.json5                       # HAR 模块声明参考
└── docs/harmony-api-guide.html        # 本文档

2.2 模块接入

  1. 把 ets/ 与 types/ 作为本地 HAR 模块放入工程（模块名保持 globecore， 与 libglobecore.so 的 nm_modname 一致）；两个 .so 放入模块 src/main/cpp/libs/arm64-v8a/ 或 build-profile 配置的 jniLibs 目录。
  2. 模块 oh-package.json5 声明 native 类型依赖： 
    "dependencies": {
  "libglobecore.so": "file:./src/main/cpp/types/libglobecore"
}
  3. cacert.pem 放 src/main/resources/rawfile/ca/；需要 PROJ 转换时， 把主仓 build-scripts 生成的 proj/（proj.db 与格网改正数）放 rawfile/proj/。
  4. 模块 module.json5 声明 "type": "har"，宿主 entry 申请网络权限： 
    "requestPermissions": [{ "name": "ohos.permission.INTERNET" }]

2.3 启动初始化（EntryAbility）

import { NativeNet, NativeSrs } from 'globecore';

export default class EntryAbility extends UIAbility {
  onCreate(): void {
    // HTTPS 瓦片证书校验（首次联网前调一次，幂等）
    NativeNet.initCaBundle(this.context);
    // 仅当用到 PROJ 坐标转换时需要；内部把 rawfile/proj 解压到 filesDir/proj
    NativeSrs.initProjData(this.context);
  }
}
内网 http:// 明文地址需在宿主调试策略中放行 cleartext；生产环境优先 HTTPS。

3. 快速开始（最小可运行示例）

以下页面创建 3D 地球、加载 ArcGIS 影像与天地图注记、开启地形并飞到中国上空：

import { NativeMapView, ViewMode, Camera, AltitudeMode } from 'globecore';

@Entry
@Component
struct MapPage {
  private map?: NativeMapView;
  // 应用私有缓存目录（瓦片/地形/矢量各自分子目录，必须互相隔离）
  private baseDir = getContext(this).filesDir + '/map-cache';

  build() {
    Column() {
      NativeMapView({
        onReady: (view: NativeMapView) => {
          this.map = view;
          // ① 影像底图（XYZ 模板，占位符 {z}/{x}/{y}，maxLevel=18）
          view.addTileLayer(this.baseDir + '/arcgis-img',
            'https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}',
            18, false);
          // ② 透明注记层：overlay=true 置顶透明混合
          view.addTileLayer(this.baseDir + '/tdt-cia',
            'https://t{s}.tianditu.gov.cn/DataServer?T=cia_w&x={x}&y={y}&l={z}&tk=YOUR_TOKEN',
            18, true);
          // ③ 三维地形（quantized-mesh 服务，目录下需有 layer.json）
          view.configureTerrainProvider(
            'https://your-host/terrain/cesium',
            this.baseDir + '/terrain', 15, 4, 3, {});
          view.setTerrainProviderEnabled(true);
          // ④ 3D 球体并飞至中国上空
          view.setViewMode(ViewMode.THREE_D);
          view.flyToCamera(new Camera(34.5, 108.9, 6000000, 0, 0, 0,
            45, AltitudeMode.ABSOLUTE), 2200);
        }
      })
        .width('100%').height('100%')
    }
  }
}
组件 aboutToAppear 自动创建 native 实例，aboutToDisappear 自动 detach+destroy，宿主无需手动管理句柄。

4. 生命周期与线程模型

  • GL 线程：XComponent(SURFACE) 提供窗口，native 侧 MapRenderHost 起独立 EGL 渲染线程接管 GL 生命周期。
  • 按需渲染：默认 RENDERMODE_WHEN_DIRTY 语义，静止不重绘省电；手势、相机变化、瓦片异步到位会触发重绘，也可手动 requestRender()。
  • 后台线程池：瓦片下载、磁盘缓存、图片解码在 native 后台线程；纹理上传切回 GL 线程按帧限额执行。
  • 线程安全：ArkTS 门面方法只做状态更新与 NAPI 转发，可在任意线程调用（含 Surface 创建前）；矢量读取为异步流程，用 hasVectorLoading() 轮询。
  • 触摸：SURFACE 型 XComponent 不投递 ArkTS .onTouch，手势在 native 识别；单击/长按经 NAPI 回调到 setOnTapListener / setOnLongPressListener，惯性由渲染线程自驱动。

6. NativeMapView API 参考

以下方法均为 NativeMapView 组件的实例方法；组件构造参数 { onReady?: (view) => void }， native 就绪后回调，未就绪时调用会被门面安全忽略。

6.1 相机与视图模式

setViewMode / getViewMode 原生

setViewMode(mode: ViewMode): void
getViewMode(): ViewMode

切换 2D 墨卡托正交与 3D 球体透视，共用一套相机，切换保持视角连续。

map.setViewMode(ViewMode.THREE_D);

setCamera / getCamera 原生

setCamera(camera: Camera): void
getCamera(): Camera | undefined

即时设置/读取相机姿态（无动画）。

flyToCamera @Jin 新增

flyToCamera(camera: Camera, durationMs: number = 1600): void

平滑飞行到目标相机；动画由 C++ GL 帧循环推进，不阻塞 ArkTS 线程。durationMs <= 0 等价即时跳转。

map.flyToCamera(new Camera(34.2196, 108.9594, 700, 0, 30, 0, 45, AltitudeMode.ABSOLUTE), 2200);

panBy / zoomBy / rotateBy / tiltBy 原生

panBy(dxVp: number, dyVp: number): void
zoomBy(scaleFactor: number, focusX: number, focusY: number): void
rotateBy(deltaDeg: number): void
tiltBy(deltaDeg: number): void

编程式相机操作：平移（vp 像素）、以 (focusX,focusY) 为焦点缩放、航向旋转、俯仰增量（仅 3D）。 @Jin 改造 panBy 在 native 侧带单帧阈值兜底，配合 ArkTS 手势识别器消除多指切换跳变。

map.zoomBy(1.5, x, y);  // 在 (x,y) 处放大 1.5 倍
map.tiltBy(10);         // 倾角 +10°

is3DMode / isReady / isNativeReady / getHandle 原生

is3DMode(): boolean
isReady(): boolean
getHandle(): number

状态查询；getHandle() 返回 native 句柄（int64），0 表示未就绪，一般业务无需使用。

6.2 手势与点击回调

setOnTapListener / setOnLongPressListener 原生 @Jin 防跳改造

setOnTapListener(listener?: (x: number, y: number) => void): void
setOnLongPressListener(listener?: (x: number, y: number) => void): void

回调坐标为组件内像素。传 undefined 反注册。平移/捏合/惯性/双指旋转俯仰由组件内置； 多指→单指切换与依次抬指的跳变已在 native 与 ArkTS 双层治理。

map.setOnTapListener((x, y) => {
  const pos = map.screenToGeo(x, y);   // 屏幕点反算经纬度
  if (pos) console.info('tap geo:', pos.longitude, pos.latitude);
});
// 长按做逆地理编码：请求天地图 geocoder 后用叠加层弹 popup
map.setOnLongPressListener((x, y) => this.reverseGeocode(x, y));

6.3 瓦片图层

addTileLayer 原生

addTileLayer(cacheDir: string, urlTemplate: string, maxLevel: number, overlay?: boolean): void
参数说明
cacheDir应用私有缓存目录；以 .mbtiles 结尾走 SQLite 单文件，否则按 z/x_y.tile 目录落盘。每层独立目录
urlTemplateXYZ URL 模板，含 {z}/{x}/{y} 占位（部分服务用 {l}）；空串=纯离线读缓存
maxLevel图源最大级别，超出后拉伸末级纹理，不出 404 占位
overlaytrue=透明注记层置顶混合；false=底图
map.addTileLayer(this.baseDir + '/base',
  'https://t0.tianditu.gov.cn/img_w/wmts?SERVICE=WMTS&REQUEST=GetTile&VERSION=1.0.0' +
  '&LAYER=img&STYLE=default&TILEMATRIXSET=w&FORMAT=tiles&TILEMATRIX={z}&TILEROW={y}&TILECOL={x}&tk=TOKEN',
  18, false);

addTileLayerWithOptions @Jin 新增 实验

addTileLayerWithOptions(cacheDir: string, urlTemplate: string, maxLevel: number, overlay: boolean,
  crs: string, tmsY: boolean, tileMatrixOffset: number): void
参数说明
crsEPSG:3857（默认，Web 墨卡托）或 EPSG:4326 / EPSG:4490（地理切片，根 2x1、纬度线性，引擎相交重投影到墨卡托球体；4490 与 4326 椭球差异亚米级按同方案处理）
tmsYtrue=TMS 行序（y 自南向北）；XYZ 服务传 false
tileMatrixOffset服务 TileMatrix 与 z 的偏移；天地图 c 服务 TILEMATRIX 从 1 起，传 1
// 天地图 4490 影像（img_c）+ 注记（cia_c）
map.addTileLayerWithOptions(this.baseDir + '/tdt4490-img',
  'https://t{s}.tianditu.gov.cn/DataServer?T=img_c&x={x}&y={y}&l={z}&tk=TOKEN',
  18, false, 'EPSG:4490', false, 1);
map.addTileLayerWithOptions(this.baseDir + '/tdt4490-cia',
  'https://t{s}.tianditu.gov.cn/DataServer?T=cia_c&x={x}&y={y}&l={z}&tk=TOKEN',
  18, true, 'EPSG:4490', false, 1);
已知边界（见主仓 docs/design/epsg-4490-*）：4490 注记存在轻微纵向拉伸与字号偏小， 后续计划以单图层 serviceZoomOffset 参数交由使用方调节，当前未开放。

addTileLayerWithLayerOptions @Jin 新增 实验

addTileLayerWithLayerOptions(cacheDir: string, urlTemplate: string, maxLevel: number, overlay: boolean,
  options: TileLayerInitOptions): void

@Jin layer-init-options：以 options 对象一次性传入建层参数，字段全部可选，缺省与 addTileLayerWithOptions 旧默认值一致； 其中 serviceZoomOffset 建层即写入（首帧选瓦即带偏移），无需建后补调 setLayerZoomOffset。运行时 setter 仍可覆盖初值。

options 字段说明
crs?: string同旧位置参数：EPSG:3857（默认）/ EPSG:4326 / EPSG:4490
tmsY?: booleantrue=TMS 行序；XYZ 服务缺省 false
tileMatrixOffset?: number服务 TileMatrix 与 z 的偏移（天地图 c 服务传 1）
serviceZoomOffset?: number单图层取瓦级别偏移，引擎钳制 [-3,2]，缺省 0 与旧行为一致；负值请求更粗一级瓦片（观感放大注记字号）
// 天地图 4490 注记层建层即带 -1 偏移（影像/注记可各自独立取值）
map.addTileLayerWithLayerOptions(this.baseDir + '/tdt4490-cia',
  'https://t{s}.tianditu.gov.cn/DataServer?T=cia_c&x={x}&y={y}&l={z}&tk=TOKEN',
  18, true, { crs: 'EPSG:4490', tmsY: false, tileMatrixOffset: 1, serviceZoomOffset: -1 });
// 运行时仍可覆盖：map.setLayerZoomOffset(labelIndex, 0);
回退：不传 options 或 serviceZoomOffset 恒为 0 即恢复旧行为；旧 addTileLayer/addTileLayerWithOptions 签名保留不变。

setLayerVisible / removeTileLayer 原生

setLayerVisible(index: number, visible: boolean): void
removeTileLayer(index: number): void

index 为 addTileLayer/addRasterLayer 的加入次序（0 起）；隐藏层不绘制、不取瓦片；移除为墓碑语义。

6.4 本地栅格影像 LITE 受限

@Jin LITE 状态：当前 lite 分发包中 addRasterLayer / addRasterImageLayer 为桩实现， 调用恒失败：返回 -1，rasterAddError()/rasterImageError() 取到中文错误「当前为 LITE 构建（未链接 GDAL），不支持本地栅格文件直读」。 tif/img 本地直读需 GLOBECORE_LITE=OFF 全量包；在线 XYZ 瓦片不受影响。

addRasterLayer / addRasterImageLayer 原生

addRasterLayer(cacheDir: string, path: string): number // 返回图层 index，-1 失败
addRasterImageLayer(cacheDir: string, path: string): number
rasterAddError(): string | null
setRasterImageVisible(index: number, visible: boolean): void
hasRasterLoading(): boolean
rasterImageError(index: number): string | null

双通路：addRasterLayer native 重投影后按墨卡托即时切片并回写缓存（级别随栅格分辨率推算）； addRasterImageLayer 整幅直读单张贴图按 WGS84 四至贴面（UI 线程零 GDAL 立即返回，超限沿 overviews 降采样）。 失败原因用对应 error 方法取中文串。Harmony LITE 无 GDAL，此能力在 LITE 包不可用。

async function loadIcon(path: string): Promise<[number[], number, number]> {
  const buf = await fs.readFile(path);
  const image = await image.createImageSource(buf.buffer).createPixelMap();
  const w = image.getImageInfoSync().size.width;
  const h = image.getImageInfoSync().size.height;
  const px = new ArrayBuffer(w * h * 4);
  await image.readPixelsToBuffer(px);
  // 注意 RGBA→引擎约定的 ARGB 位模式打包
  const u8 = new Uint8Array(px); const argb: number[] = [];
  for (let i = 0; i < u8.length; i += 4) {
    argb.push(((u8[i+3]<<24) | (u8[i]<<16) | (u8[i+1]<<8) | u8[i+2]) | 0);
  }
  return [argb, w, h];
}

13.8 长按逆地理编码（天地图 geocoder + popup）

map.setOnLongPressListener(async (x, y) => {
  const pos = map.screenToGeo(x, y);
  if (!pos) return;
  const url = 'https://api.tianditu.gov.cn/geocoder?post={' +
    '"lon":' + pos.longitude + ',"lat":' + pos.latitude + ',"ver":"1"}&type=geocode&tk=' + TK;
  const resp = await http.createHttp().request(url);
  const addr = JSON.parse(resp.result as string).result?.formatted_address ?? '未知地址';
  this.showPopup(x, y, addr);   // 宿主 ArkTS 自绘 popup，带关闭按钮
});

14. 排错指南

现象可能原因处理
so 加载失败 / 符号找不到ABI 不匹配或模块名不一致确认 arm64-v8a；so 名必须 libglobecore.so，nm_modname=globecore，import 名大小写一致
黑屏无瓦片无网络权限 / URL 模板错误 / HTTPS 证书未初始化检查 INTERNET 权限、{z}{x}{y} 顺序、调 NativeNet.initCaBundle；hilog 过滤 globecore
HTTPS 瓦片慢未配置 CA，每块降级双握手rawfile 放 cacert.pem 并启动时 initCaBundle
坐标转换返回 nullproj.db 未解压或 CRS 字符串非法先 NativeSrs.initProjData；用 'EPSG:4326' 标准写法
地形没有起伏仍在 2D / 地形未开 / layer.json 失败切 THREE_D；terrainProviderStatus() 看 metadataLoaded；监听 error 事件
在线 GeoJSON 加载失败非 2xx、HTML 登录页、空响应、超 80MB浏览器直连验证 URL；hilog 搜 [RemoteGeoJson]；内网 http 放行 cleartext
大 GeoJSON 卡顿一次顶点过多用 extent/maxFeatures、updateVectorExtent 分视口加载、简化几何
addRasterLayer 返回 -1 / 提示不支持本地栅格lite 包无 GDAL，本地栅格为桩改用在线瓦片；或构建 GLOBECORE_LITE=OFF 全量包
NativeSrs.convert 恒返回 null、getProjVersion=0lite 包 PROJ 为桩全量包 + 初始化 NativeSrs.initProjData
加载 shp/kml 提示仅支持 GeoJSONlite 包 OGR 为桩，只保留原生 GeoJSON reader转 GeoJSON 加载，或使用全量包
4490 注记字小/轻微拉伸地理切片重投影特性（已知边界）实验性 setTileLodOffset(-1) 对比；后续单图层 serviceZoomOffset 方案
拾取不到 overlay图层 noPick 或图层顺序检查 setOverlayNoPick 与 add 顺序
手势多指跳变旧版本问题确认使用含 @Jin 防跳改造的包（main 0.1.5.0-dev 起）
hilog 常用过滤：hdc shell hilog | grep globecore； 地形关注 CesiumTerrainProvider，在线矢量关注 [RemoteGeoJson]/[LiteGeoJson]， 瓦片关注 TileLoader/TileCache。
