1. SDK 概览与架构

GlobeCore 是以 C++ 为核心的地图渲染引擎。HarmonyOS NEXT 侧通过 NAPI 把 libglobecore.so 暴露为 ArkTS 门面，ArkUI 使用 XComponent 承载 EGL 渲染面。业务 App 只需要接触 NativeMapView 与几个值对象类，不直接调用 NAPI。

NativeMapView
地图组件本体（封装 XComponent + EGL + 触摸路由 + NAPI 句柄），负责相机、瓦片/地形/矢量图层、手势、拾取与屏幕反算。
Camera / Position
相机姿态（经纬高 + heading/tilt/roll + fov）与地理位置值对象，经纬度单位为度，高度单位为米，角度单位为度。
VectorStyle / VectorExtent
矢量样式（颜色为 #AARRGGBB 打包数值）与空间过滤矩形。
CesiumTerrainProvider
quantized-mesh 地形服务适配：layer.json 元数据、磁盘缓存、视口自动跟随、并发与事件。
NativeSrs / NativeVector / NativeLayerInfo
PROJ 坐标转换、矢量文件 IO 与图层元信息（LITE 构建为桩实现，见第 15 节）。
模块文件：library/src/main/ets/ 下 NativeMapView.ets（地图）、Camera.ets、Position.ets、VectorStyle.ets、VectorExtent.ets、FeatureGeometry.ets（含 PickResult）、NativeLib.ets（NAPI 薄封装，业务一般不直接用）、terrain/CesiumTerrainProvider.ets。

2. 集成与权限

2.1 oh-package 依赖

entry 模块的 oh-package.json5 以 file: 协议依赖本地 HAR 模块（Demo 工程用目录软链接 library -> vendor/GlobeCore/globecore-harmonyos/library）：

"dependencies": {
  "@zys/globecore": "file:../library"
}

2.2 权限

在线瓦片、地形、在线 GeoJSON 需要网络权限；本地矢量/栅格读取应用沙箱文件无需额外权限：

"requestPermissions": [
  { "name": "ohos.permission.INTERNET" }
]
HTTP 明文：内网调试的 http:// 服务需在 module.json5 / 网络安全配置中允许 cleartext；生产环境优先 HTTPS。

2.3 构建形态

HAR 的 native 由 build-profile.json5 的 -DGLOBECORE_LITE=ON/OFF 决定 LITE / FULL 形态（见第 15 节）。分发包命名必须带 -lite / -full 标记。

3. 最小地图示例

import { NativeMapView, Camera, ViewMode } from '@zys/globecore';

@Entry @Component struct MapPage {
  build() {
    Stack() {
      NativeMapView({
        density: display.getDefaultDisplaySync().densityPixels, // 真实 DPR，必须传
        vectorCacheDir: this.context.filesDir + '/globecore/vector-cache',
        onReady: (view: NativeMapView) => {
          // 1) 影像底图（不透明）
          view.addTileLayer(this.context.filesDir + '/map-cache/arcgis-img',
            'https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}',
            18, false);
          // 2) 透明注记叠加层（overlay=true，开 alpha 混合）
          view.addTileLayer(this.context.filesDir + '/map-cache/arcgis-ref',
            'https://server.arcgisonline.com/ArcGIS/rest/services/Reference/World_Boundaries_and_Places/MapServer/tile/{z}/{y}/{x}',
            18, true);
          // 3) 初始相机：3D 全球视角，中心在中国
          view.setViewMode(ViewMode.THREE_D);
          view.setCamera(new Camera(35.5, 104.0, 22000000.0, 0.0, 0.0));
        }
      }).width('100%').height('100%')
    }
  }
}
URL 模板：占位符为 {z}/{x}/{y}（XYZ，y=0 在北）；TMS 服务（y=0 在南）使用带 options 的接口并传 tmsY=true。Token 由宿主在传入前替换。

4. 生命周期与线程

主题约定
线程模型ArkTS 方法可在 UI 线程调用；native 内部用图层锁 + GL 线程消息队列，瓦片下载/解码在后台线程池，纹理上传与绘制只在 EGL 渲染线程。
onReady 时机XComponent surface 创建、native 引擎构造完成后回调一次；图层添加、相机设置必须在 onReady 之后。
重绘写接口内部自动 requestRender；连续相机变化由手势/飞行驱动，宿主无需手动刷帧。
页面退出NativeMapView 实现 aboutToDisappear 释放 EGL/TSFN；宿主注册的回调随页面置空即可。
多实例句柄模型支持多 NativeMapView 实例，各自独立引擎与缓存。

5. Camera / AltitudeMode / ViewMode

Camera

class Camera {
  latitude: number;      // 纬度（度，WGS84）
  longitude: number;     // 经度（度）
  altitude: number;      // 高度（米）
  heading: number;       // 航向角（度，顺时针自北为正；仅 3D 消费）
  tilt: number;          // 倾斜角（度，0=正射俯视，接近 90=平视地平线；仅 3D 消费）
  roll: number;          // 翻滚角（度，一般保持 0）
  fieldOfView: number;   // 视场角，默认 45
  altitudeMode: AltitudeMode;
  constructor(lat?, lon?, alt?, heading?, tilt?, roll?, fov?, altMode?)
}

等价的 Cesium 俯仰角 pitch = tilt − 90（−90=俯视，0=平视）。

AltitudeMode（枚举值与 native 严格一致，勿调整顺序）

enum AltitudeMode { ABSOLUTE = 0, ABOVE_SEA_LEVEL = 1, CLAMP_TO_GROUND = 2, RELATIVE_TO_GROUND = 3 }

ViewMode

enum ViewMode { TWO_D = 0, THREE_D = 1 }   // 2D 平面墨卡托正交 / 3D 球体透视，共用相机状态，切换视角连续

7. VectorStyle

颜色统一为 #AARRGGBB 打包数值（无符号十六进制字面量，如 0x664A8FE3）；线宽单位像素，点半径单位 dp。

字段含义默认
fillColor面填充色0x664A8FE3 半透明蓝
outlineColor / outlineWidth面描边色与线宽白 / 1.0
lineColor / lineWidth线要素色与线宽橙红 0xFFE56B33 / 2.0
pointColor / pointRadiusDp点色与屏幕固定半径橙红 / 5dp
fillExplicit / lineExplicittrue=覆盖 KML 逐要素原色false
labelField / labelColor / labelSize / labelOutline / labelOutlineColor标注字段名（空=不标注）、文字色、字号缩放、描边开关与描边色白字、1.0、黑描边
featureStyleOverride单要素样式覆盖串，; 分隔条目、, 分隔 8 字段空串

8. PickResult / FeatureGeometry

class PickResult { layerIndex: number; fid: number }   // 拾取命中：图层序号 + 源要素 ID
class FeatureGeometry {
  type: number;              // 0=点、1=线、2=面
  lonlat: number[];          // 摊平 [lon0,lat0,lon1,lat1,...]，与 updateOverlay* 同构
  ringCounts: number[];      // 线：每段顶点数；面：每环顶点数；点为空
  ringsPerFeature: number[]; // 面专用，每要素环数（首环外环、余为洞）
}

9. 相机与视图模式

setCamera(camera: Camera): void

整体写入相机姿态，立即生效。

flyToCamera(camera: Camera, durationMs: number = 1600): void C++ 平滑飞行

在指定毫秒内插值飞达；durationMs ≤ 0 退化为 setCamera。飞行期间手势可打断。

view.flyToCamera(new Camera(33.956, 107.78, 50000, 0, 55), 2200);

getCamera(): Camera | undefined

读回当前完整姿态（句柄已释放返回 undefined），可用于 HUD 显示 tilt/heading。

setViewMode(mode: ViewMode) / getViewMode(): ViewMode

切换 2D/3D；两模式共用相机，视角保持连续。

cameraZoomLevel(): number

相机界面显示级别（displayLevel，与相机高度/视口/DPR 相关）。

10. 手势与触摸回调

XComponent 内部已接线 MapGestures：单指平移、双击/捏合缩放（以焦点为锚）、双指旋转 heading、双指纵向俯仰 tilt（仅 3D），手势结束后触发瓦片细化。宿主一般只用下列编程接口与回调：

API说明
panBy(dxVp, dyVp)编程平移（vp 单位）。
zoomBy(factor, focusXVp, focusYVp)以焦点为锚缩放，factor>1 放大。
rotateBy(deltaDeg) / tiltBy(deltaDeg)航向/倾角增量（度），tilt 内部钳制在 [0, MAX_TILT]。
viewHeightVp() / getViewHeightVp()视口高（vp），手势灵敏度换算用。
setOnTapListener(cb)单击回调，入参为 native 触摸原始 px 坐标，可直接喂给 pickVector/screenToGeo。
setOnLongPressListener(cb)长按回调；普通模式可做逆地理编码，绘制模式可结束线/面。

11. XYZ 瓦片图层

addTileLayer(cacheDir, urlTemplate, maxLevel, overlay = false): void

添加在线/缓存瓦片层。每层独立磁盘缓存（cacheDir/<z>/<x>_<y>.tile）与 6 线程加载器；未命中才联网，非 2xx（含 429）不写缓存。overlay=true 为透明注记层，开 alpha 混合、缺失瓦片保持透明不画占位块。

addTileLayerWithOptions(cacheDir, urlTemplate, maxLevel, overlay, crs, tmsY, tileMatrixOffset): void 实验·EPSG:4326/4490

参数说明
crs""/EPSG:3857=Web 墨卡托（默认）；EPSG:4326/EPSG:4490=地理切片（根 2×1、纬度线性），引擎内重采样到墨卡托瓦，原始瓦缓存目录自动加 -geo-raw 后缀隔离。
tmsYtrue=TMS 行序（y=0 在南），false=XYZ（y=0 在北）。天地图 c 传 false。
tileMatrixOffset服务 TILEMATRIX 相对 0 基层级的偏移；天地图 c 根 2×1 记矩阵 1，传 1。
// 天地图 img_c/cia_c（EPSG:4490 地理切片）
view.addTileLayerWithOptions(cacheImg, imgUrl, 18, false, 'EPSG:4326', false, 1);
view.addTileLayerWithOptions(cacheCia, ciaUrl, 18, true,  'EPSG:4326', false, 1);

setLayerVisible(index, visible): void

按加入次序 index 显隐图层；隐藏层不绘制、不请求瓦片。

removeTileLayer(index): void

墓碑化移除（不压缩数组，其他层 index 不变），旧层排队请求立即取消，GL 纹理在下一帧回收。

index 维护：native 采用墓碑机制而非数组压缩，宿主应自行保存每次 addTileLayer 返回的逻辑序号（Demo 用 nextTileLayerIndex 递增维护影像/注记两个 index）。

12. LOD 级别诊断与偏移（含单图层 serviceZoomOffset）

tileZoomLevel(maxLevel = 18): number

只读：当前相机在指定图源上限下的全局目标瓦片 LOD，与 cameraZoomLevel（界面级别）同屏对比可定位高 DPR 屏的细分偏差。3D 四叉树仍会按距离/SSE 在其附近混合更粗叶。

setLayerZoomOffset(index, offset): void 实验·可回退·2026-11-11 新增

单图层瓦片 LOD 偏移，只改变 index 指定图层的取瓦级别，不影响相机与其他图层。

offset整数，引擎内钳制到 [-3, 2]；0=标准（默认，与改造前行为完全一致），负数请求更粗父瓦。
生效路径2D：在 Navigator 全局 LOD 结果上逐层叠加并钳制 [MIN_LEVEL, maxLevel]，可见范围/请求/祖先链/绘制统一使用调整后的级别；3D：同步调整 targetLevel、四叉树细化帽与 SSE 因子（ldexp(1,-offset)），交互 LOD 迟滞按偏移维度隔离。
与全局偏移关系正交可叠加：最终级别 = 全局 setTileLodOffset 结果 + 本层 serviceZoomOffset。
典型用途高 DPR 屏注记字号偏小时仅把注记层设 -1/-2；天地图限流时仅降低个别图层请求量。
持久化不持久化，应用重启恢复 0；切换图源重建图层后需由宿主重新设置（Demo 在 addImagerySource 尾部自动重放）。
回退移除 TileLayer.serviceZoomOffset 字段与 setLayerZoomOffset 调用链即恢复；不传不调零影响。
// 只把注记层（index=1）降低 1 级取瓦，影像层（index=0）保持标准
view.setLayerZoomOffset(0, 0);
view.setLayerZoomOffset(1, -1);

setTileLodOffset(offset): void 实验·全局

Navigator 级全局偏移（[-3,2]），所有瓦片层一起受影响；保留用于整体对照，新需求优先使用单图层版本。

setTileLodAlignDisplay(align): void 实验·对照

true 时强制瓦片 LOD = 相机 displayLevel，忽略视口/FOV/DPR 的屏幕误差补偿，仅用于字号与请求量对照实验。

13. 三维地形 Provider（C++ 调度）

地形下载与调度已下沉到 C++ CesiumTerrainProvider，ArkTS 侧仅做服务配置与事件接收，适配 Cesium quantized-mesh v1.0 服务（layer.json + .terrain 瓦片）。

API说明
setTerrainProviderEnabled(enabled): boolean开/关地形；返回 false 表示 Provider 未配置。仅 3D 模式消费。
refreshTerrainProvider(): void按当前相机视口强制刷新（连续请求 native 自动合并）。
setTerrainProviderAutoFollow(enabled): void开启后相机移动自动跟随刷新视口地形（Demo 默认开）。
prefetchTerrainProviderMetadata(): void后台预取 layer.json 元数据。
terrainProviderStatus(): stringProvider 当前状态 JSON 串。
setOnTerrainProviderEventListener(cb)事件回调：metadata_started/metadata_ready、瓦片进度、失败统计等（payload 为 JSON 字符串）；页面退出时传 undefined 注销。
setTerrainTile(z,x,y,bytes,bbox) / clearTerrain()早期宿主自下载通路的逐瓦注入/清空接口；使用 C++ Provider 后一般不再需要。
父级回退（实验）：服务 layer.json 声明覆盖但高层级瓦片 404 时，Provider 自动按 EPSG:4326 地理网格回退最近可用祖先瓦片（父索引=子 x/y 整除 2），缺失负缓存上限 4096，手动刷新/切图源清空重探。
view.setOnTerrainProviderEventListener((p: string) => this.onTerrainEvent(p));
view.setTerrainProviderAutoFollow(true);
view.prefetchTerrainProviderMetadata();
view.setViewMode(ViewMode.THREE_D);
view.setTerrainProviderEnabled(true);

14. 3D Tiles 倾斜摄影 实验·可回退

API说明
addTileset3D(url): number加载 tileset.json（3D Tiles 1.0，b3dm 三角网），返回 layerId；支持 transform/boundingVolume、RTC_CENTER、嵌套 tileset、相对 URL。当前纯色 + Lambert 渲染（纹理解码已支持，PBR/i3dm/pnts/cmpt 待后续）。
setTileset3DVisible(layerId, visible)显隐，图层复用不重复创建。
setTileset3DHeightOffset(layerId, meters)沿锚点 ECEF 天顶整体平移模型（只改绘制 uniform、不重建），用于校准模型与地形的高程基准差；默认 0。

15. 文件 / 在线矢量（GeoJSON）

addVectorLayer(path, style, iconArgb?, iconW?, iconH?, extent?, maxFeatures?): number

path 既支持沙箱本地文件，也支持 http(s) 在线 GeoJSON URL（实验性在线 Source，轻量嗅探 + OGR/lite 解析，默认上限 80MB）。返回图层 index；后台读取不阻塞 UI，就绪后 GL 线程同帧替换。

const idx = view.addVectorLayer(
  'http://host/path/province.json',
  new VectorStyle(0x334A8FE3, 0xFFFFFFFF, 1.5),
  undefined, 0, 0,
  new VectorExtent(105.0, 31.0, 111.0, 39.5), 5000);
updateVectorExtent(index, extent, maxFeatures=0)相机静止后按新视口重载（在线 URL 仅重读已下载缓存，不重新请求）。
setVectorLayerVisible(index, visible)显隐；隐藏层不读取/不上传/不可拾取。
setVectorMinLevel(index, minLevel)显示级别下限，相机级别不足时整层隐藏；≤0 不限。
hasVectorLoading(): boolean是否仍有可见层在读取/建几何/流式上传，供“加载中”提示轮询。
removeVectorLayer(index)墓碑移除，index 不压缩。

16. 动态叠加层（内存几何）

用于测量、轨迹、拍照标识、业务点线面：每类叠加“加一次、就地更新多次”，与文件矢量共享索引空间和绘制/拾取通路。

API说明
addOverlayLayer(style, iconArgb?, iconW?, iconH?): number新建空叠加层，返回 index；图标点传 ARGB 像素数组。
updateOverlayPoints(index, lonlat, fids?, labels?)覆盖式更新点；lonlat 摊平 [lon,lat,...]，labels 非空串才标注。
updateOverlayLines(index, lonlat, vertexCounts, fids?, labels?)折线；vertexCounts[f] 为第 f 条线顶点数。
updateOverlayPolygons(index, lonlat, ringVertexCounts, ringsPerFeature, fids?, labels?)多边形；首环外环、余为岛洞。3D 开启地形时走 drape 贴地通路。

18. 拾取与屏幕反算

pickVector(sxPx, syPx): PickResult | undefined像素坐标拾取矢量/叠加要素，返回 layerIndex + fid；noPick 层与隐藏层自动跳过。

19. NativeSrs 坐标转换

NativeSrs.initProjData(context);                 // 首次转换前调用一次，解压 rawfile/proj
const p = NativeSrs.convert(x, y, 'EPSG:4490', 'EPSG:3857'); // [x', y']，失败 null
const v = NativeSrs.getProjVersion();
LITE 构建无 PROJ 静态库，NativeSrs 为桩实现（返回 null/0），需要坐标转换必须使用 FULL 构建。

21. LITE / FULL 能力边界

能力LITE（GLOBECORE_LITE=ON）FULL（OFF）
在线 XYZ 瓦片（含 EPSG:4490 重采样）✅✅
三维地形 Provider / 父级回退✅✅

PROJ 坐标转换、NativeVector SQL/属性写回❌ 桩✅

view.setLayerZoomOffset(1, -1);

const idx = view.addVectorLayer(

view.setOnLongPressListener((px: number, py: number) => {

23. 排错指南

现象可能原因处理
瓦片不出图无 INTERNET 权限、URL 模板/ token 错误、429 限流、tmsY 行序反查权限与 {z}/{x}/{y} 顺序；缓存命中应先显示；换 tmsY 验证行序。
4490 图层错位/拉伸crs/tileMatrixOffset 传参错误天地图 c 传 ('EPSG:4326', false, 1)；确认缓存目录与墨卡托源隔离。
setLayerZoomOffset 无效index 不是当前图层序号（切图源后旧 index 已墓碑）用最新 addTileLayer 的逻辑序号重新设置。
地形无起伏仍在 2D、未 enable、layer.json 失败切 THREE_D，看 terrainProviderStatus 与事件 payload。
文字不显示/豆腐块未加载中文字体onReady 内 setFontPath('/system/fonts/HarmonyOS_Sans_SC.ttf')。
坐标转换返回 nullLITE 无 PROJ 或未 initProjData改用 FULL 构建并先初始化 PROJ 数据。
怀疑装了旧 HARohpm 缓存/未重装查 hilog 中 globecore build id = ... 是否为本次 GLOBECORE_BUILD_ID；卸载重装。
在线 GeoJSON 解析失败服务返回 HTML/空体、超 80MB浏览器直连验证；服务端切片或后续开放 maxNetworkBytes。
